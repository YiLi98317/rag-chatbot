# 手机妈妈 AI 助手 · 知识整理指南（给商务/客服/业务员）

> 一句话：我们在做一个"公司规则大脑"（AI 助手马三多）。它不会自己编，全靠**我们给的标准答案和知识**。
> 你**不需要懂技术**，只要把"正确的说法"整理进表格和文档就行。

---

## 你要整理三样东西

### 1️⃣ 审"标准答案表"（最重要，先做这个）
- **文件**：`business_review/golden_review.xlsx`（用 Excel 打开，表头是中文，`审核状态`是下拉框，另有一页"字段说明"）
- **怎么做**：一行是一道题。看"问题 + 理想回答"对不对，在 **审核状态** 里选：
  - `确认`：答得对 → 再填"审核人、审核日期"
  - `修改`：要改 → 把正确答案写进"**修正-理想回答**"这一列
  - `删除`：这题没用 → 在"业务备注"写原因
  - `待定`：拿不准 → 在"业务备注"写卡在哪、要谁定
  - `新增`：想加新题 → 给新编号 + 问题 + 类别 + 答案
- **重点**：标"是否需业务确认=是"的题**优先看**；涉及**费用/风控/监管锁/合规**的，拿不准就写"以系统页面为准"或选"待定"，**不要为了让 AI 通过而乱写**。

### 2️⃣ 写"知识库文档"（把规则/流程/话术写清楚）
- **文件夹**：`data/knowledge/`，里面 `_templates/` 有 7 种模板，复制对应的来写：
  | 你要写什么 | 用哪个模板 |
  |---|---|
  | 平台规则/费率/结算 | `rule_template.md` |
  | 办单/锁机/审核流程 | `sop_template.md` |
  | 销售话术 | `sales_script_template.md` |
  | 不能说的话（红线） | `redline_template.md` |
  | 常见问答 | `faq_template.md` |
  | 售后/质保/丢失/逾期 | `after_sales_template.md` |
  | 系统页面操作 | `system_operation_template.md` |
- **怎么做**：复制模板 → 顶部信息（负责人、可见角色、生效日期等，每项旁边都有中文说明）填好 → 正文按小标题填。
- **重点**：**不要把和客户的原始聊天记录直接粘进来**，要提炼成"标准答案"。

### 3️⃣ 提供"真实问题 + 禁用话术"
- **真实高频问题**：把客户/加盟商实际会问的话，越口语越好，汇总一份给负责人（目标 ≥ 50 条）。
- **禁用话术清单**：绝对不能对客户说的词/说法（如把服务费说成"利息""贷款"、承诺"一定通过"等），用 `redline_template.md` 整理。

---

## 分工建议
- **商务负责人**：入驻/返点/提现/结算规则 + 红线合规。
- **客服主管**：办单/审核/锁机/售后流程 + "什么该转人工"。
- **业务员/店长**：真实问题 + 好用的销售话术。
- **运营**：活动/费用政策(带生效时间) + 禁用话术清单。

## 完成后
把填好的 `golden_review.xlsx` 和写好的知识库文档发回给技术负责人，我们会导入系统、给 AI 打分，答错的再回来补。**这是个持续过程，先把高频、标准、重复的问题做扎实即可。**
